# Dados fictícios

Usados como *seed* de desenvolvimento e testes. Nomes inventados.

- `alunos-ficticios.csv` — mesmo formato que será usado para importar os alunos reais
  (UTF-8, separador vírgula, cabeçalho obrigatório: `matricula,nome,turma,ano_letivo`).
- `professores-ficticios.csv` — turmas separadas por `;`.

Os dados reais **não** devem ser commitados neste repositório (LGPD); a importação
será feita pela tela de administração.
